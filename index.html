Часто задаваемые вопросы

Адаптивная верстка — это подход, при котором макет сайта автоматически подстраивается под размер экрана устройства пользователя: смартфона, планшета или ПК.

БЭМ (Блок-Элемент-Модификатор) помогает структурировать CSS-классы, делает код понятным, предсказуемым и легко масштабируемым в больших проектах.

Flexbox — одномерная система для выравнивания элементов в строку или колонку. CSS Grid — двумерная система, позволяющая одновременно управлять строками и столбцами.

Через DOM (Document Object Model). JavaScript может находить элементы, изменять их содержимое, стили, классы и реагировать на события пользователя.
